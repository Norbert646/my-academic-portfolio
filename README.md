# Academic Portfolio — Hossein Rezaei

A professional academic portfolio website built with React 19, TypeScript, Vite 7, Tailwind CSS v4, and Framer Motion.

## About This Project

This website serves as my academic portfolio for graduate admissions in Chemistry (specialization: Catalysis and Green Chemistry) at European universities.

It includes:
- Personal academic profile
- Education and GPA (17.9/20)
- Scientific interests (catalysis, green chemistry, organic, analytical)
- Laboratory and instrumental analysis training
- Workshops and certifications
- Industrial experience (Bid Boland Gas Refinery)
- Downloadable CV (PDF)
- Contact form (via Formspree)
- Error monitoring (Sentry)

## Tech Stack

- React 19.2.8
- TypeScript
- Vite 7
- Tailwind CSS v4
- Framer Motion
- Lucide React Icons
- Formspree (contact form)
- Sentry (error monitoring)
