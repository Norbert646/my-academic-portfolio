# Academic Portfolio — Hossein Rezaei

A professional academic portfolio website built with React 19, TypeScript, Vite 7, Tailwind CSS v4, and Framer Motion.

## About This Project

This website serves as my academic portfolio for graduate admissions in chemistry (catalysis and green chemistry). It includes:

- Personal academic profile
- Education and GPA
- Scientific interests
- Laboratory and instrumental analysis training
- Workshops and certifications
- Industrial experience
- Contact form with Formspree integration
- Downloadable CV (PDF)

## Tech Stack

- React 19
- TypeScript
- Vite 7
- Tailwind CSS v4
- Framer Motion
- Lucide React Icons
- Formspree (contact form)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Norbert646/my-academic-portfolio.git
   cd my-academic-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Project Structure

```
src/
├── components/     # React components (15)
├── data/           # Static data (profile, education, interests, etc.)
├── App.tsx         # Root component
├── index.css       # Tailwind v4 theme
└── main.tsx        # Entry point
```

This project is deployed on **Vercel**. Any push to the `master` branch automatically triggers a new deployment.
